# 🍪 Cookie

Projeto desenvolvido em **HTML, CSS e JavaScript**, com uma página interativa para apresentar diferentes sabores de cookies.

## Tecnologias

* HTML
* CSS
* JavaScript

## Sabores

* Chocolate 🍫
* Morango 🍓
* Siciliano 🍋

O projeto possui navegação entre os sabores utilizando as setas laterais.
